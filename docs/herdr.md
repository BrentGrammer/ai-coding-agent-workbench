# Herdr

Herdr can start Claude Code, Codex, Cursor, or OpenCode:

```shell
start-herdr claude
start-herdr codex /path/to/project
start-herdr cursor
start-herdr opencode
```

Herdr installs only the selected harness. It does not install Hunk or review skills.

Use it on your Mac in a [Docker sandbox](local-sandboxes.md), or on the [cloud workbench](cloud-workbench.md) box. With OpenCode it can also read from a [GPU box](local-llm.md#run-on-an-aws-gpu-box).
